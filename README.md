# 📚 Poesia Milton Duarte — Projeto Web

Um site web responsivo e elegante desenvolvido para apresentar e valorizar as poesias de **Milton Duarte**. O projeto foca em uma experiência de leitura fluida, com tipografia cuidadosa e layout adaptável a diferentes tamanhos de tela.

---

## 📌 Sobre o Projeto

O **Projeto Web Poesia Milton Duarte** foi concebido para reunir e exibir obras poéticas em um ambiente digital agradável. O objetivo principal é proporcionar ao leitor uma interface limpa, sem distrações, priorizando a legibilidade dos textos e o apelo visual através do design CSS moderno.

---

## 🚀 Tecnologias Utilizadas

O projeto foi built utilizando tecnologias puras da Web (sem frameworks ou scripts client-side):

- **HTML5**: Estruturação semântica do conteúdo para melhor acessibilidade e SEO.
- **CSS3**: Estilização completa, incluindo:
  - Layouts responsivos (Flexbox e CSS Grid).
  - Variáveis CSS (_Custom Properties_) para manutenção simplificada do tema.
  - Media Queries para adaptação a dispositivos móveis, tablets e desktops.
  - Tipografia otimizada para leitura de poesias e textos longos.

> **Nota:** Este projeto **não utiliza JavaScript**, mantendo o foco em performance, simplicidade de carregamento e compatibilidade total em qualquer navegador sem dependências de execução de scripts.

---

## 🎨 Recursos de Design & Layout

Acessibilidade & Semântica: Tags HTML5 semânticas ( header, main, article, footer ) para melhor navegação por leitores de tela.

Design Responsivo: Adaptação automática para diferentes resoluções de tela (Mobile First / Responsive Design).

Foco na Leitura: Espaçamento de linhas, margens e fontes selecionadas para uma experiência poética imersiva.

## 🔧 Como Executar o Projeto

Como o projeto é estático e construído exclusivamente com HTML e CSS, não é necessário instalar dependências ou ambiente de compilação.

1.Clone o repositório:

```Bash

git clone [https://github.com/leandro-90/projeto_web_poesia_milton_duarte.git](https://github.com/leandro-90/projeto_web_poesia_milton_duarte.git)
```

2.Acesse a pasta do projeto:

```Bash

cd projeto_web_poesia_milton_duarte
```

3.Abra o projeto:

## Basta dar um duplo clique no arquivo index.html ou abri-lo diretamente em seu navegador preferido.
